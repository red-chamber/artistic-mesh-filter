# Labeling guide

## Current labels

当前初始标签是数据集代理标签：

- Toys4K：`label=1`；
- 自选 Objaverse：`label=0`。

这只能用于建立第一版基线。它无法排除数据来源、类别、格式、面数、尺度或转换工具造成的偏差。

## Human review labels

人工盲审时隐藏：

- 数据来源；
- 文件名和路径；
- 机器预测分数；
- 正负样本目录信息。

建议标签：

| Label | Meaning |
| --- | --- |
| `accept` | 拓扑整体符合 Artistic/Low-poly 使用目标 |
| `reject` | 明显扫描化、无意义密集、随机三角化或严重退化 |
| `uncertain` | 仅凭当前视图不能稳定判断 |
| `invalid` | 无法可靠显示或几何文件不可用，不参与 Artistic 好坏判断 |

## Review criteria

重点观察：

- 平坦区域是否保持稀疏；
- 折痕、轮廓和零件边界是否获得必要边；
- 局部边流是否连续、有结构；
- 是否存在大量接近等边的小三角形；
- 是否存在大量细长、退化三角形；
- 多边形是否用于表达形状，而非无意义堆积。

人工审计集应包含高分、低分、边界样本，以及匹配面数和类别的正负样本。
