# Feature definitions

## Basic counts

- `vertex_count`：顶点数量；
- `face_count`：三角面数量；
- `edge_count`：无向唯一边数量；
- `component_count`：至少被一个面使用的顶点所形成的连通分量数量；
- `boundary_edge_count`：只被一个三角面使用的边数量；
- `nonmanifold_edge_count`：被三个或更多三角面使用的边数量。

## Face validity

- `zero_area_face_count`：面积小于等于 `zero_area_epsilon` 的面数；
- `duplicate_face_count`：忽略顶点顺序后重复的额外三角面数量。

这些指标描述几何可用性，不直接定义 Artistic 标签。

## Triangle equilateral score

对边长为 $l_1,l_2,l_3$、面积为 $A$ 的三角形：

$$
q = \frac{4\sqrt{3}A}{l_1^2+l_2^2+l_3^2}
$$

- `equilateral_ratio`：$q>0.9$ 的面比例；
- `sliver_ratio`：$q<0.05$ 的面比例；
- `small_angle_ratio`：最小内角小于 $5^\circ$ 的面比例。

不能简单认为 $q$ 越低越好：接近 1 可能表示各向同性重网格，接近 0 可能表示退化拓扑。

## Area distribution

`area_coefficient_of_variation` 是非零面积三角面的总体标准差除以均值。它仅描述面积差异，必须结合结构和局部位置解释。

## Draft Artistic features

顶点度数、一环边长变异、局部方向熵、方向连续性、曲率密度相关性和 QEM 冗余度尚未在真实数据上验证。它们已经进入配置草案，但在确认真实拓扑和格式之前不作为稳定接口。

## 实现状态

配置里 `features.*` 为 `true` 表示已实现，为 `false` 表示仅有定义、尚未实现。当前
`configs/features/artistic_v1.yaml` 里六个草案特征全部为 `false`：定义已经写死为远端实现
的契约，但代码尚未实现，因为一环邻域类定义的多几何体与实例化前提必须先由 `probe`
在真实数据上确认。实现某个特征时，必须在同一次改动里把它的开关改为 `true`。

已实现并进入特征表的是 `src/mesh_filter/features/basic.py` 中的基础计数、面合法性、
等边度与面积分布。

## 共同约定

所有草案特征都只定义在"在用顶点"上，即在用顶点是指至少属于一个三角面的顶点；孤立
顶点不计入任何统计。所有长度量与坐标同时归一化，因此特征对平移和统一缩放不变。

正式实现前必须先跑 `probe`，确认真实数据是否含多几何体、实例化或非单位变换，否则
"一环邻域"在一份资产内可能跨越多个几何体，定义需要先明确边界。

## 草案特征规格

以下规格是远端实现的唯一依据。实现后如需修改定义，必须新建 `artistic_v2.yaml` 并同时
更新本文档，不要就地改动 `v1`。

`vertex_degree_histogram`
: 顶点度 = 与顶点相连的不同顶点数。按度 k 分箱，k 从 1 到 12，度大于 12 并入
  `degree_ge_13`。每个分箱输出该度数在用顶点占全部在用顶点的比例。

`one_ring_edge_length_cv`
: 对每个在用顶点，取一环边长集合 $\{L_e\}$，算变异系数 $\mathrm{CV} = \sigma(L)/\mu(L)$，
  单元素或长度为零的环记 0。输出所有顶点 CV 的中位数，避免少量长边主导整体读数。

`local_edge_direction_entropy`
: 对每条无向边取其单位方向向量，在边中点的 k 近邻集合内（默认 `k = 8`）把方向映射到
  单位球上的分箱直方图，计算香农熵并按 $\log$ 分箱数归一化到 $[0,1]$，最后对所有边取
  均值。数值低表示局部边方向集中、有结构；数值高表示方向杂乱。

`neighboring_direction_consistency`
: 对每个在用顶点，取其入射边的单位方向集合，计算所有两两组合夹角余弦绝对值的均值，
  再对所有顶点取均值。两条共线边给出 1，垂直给出 0。与上一条的区别是这里不做空间
  邻域搜索，只看向同一个顶点的边。

`curvature_density_correlation`
: 顶点离散曲率用二面角加权（或先用顶点缺陷近似），局部面密度用一环面面积均值。输出
  两者在所有在用顶点上的 Spearman 相关系数。正相关表示曲率高处面更密，符合手工低模
  的做法；接近 0 或负相关表示密度与形状无关，常见于自动重网格或扫描简化。

`qem_redundancy`
: 对每个在用顶点计算二次误差 $e(v)$，即删除该顶点时引入的几何误差，用网格包围盒对角
  线长度的平方归一化，使不同尺度可比。输出 $e$ 的均值与中位数。平坦区域顶点过密时该
  值很小，是"无意义堆积多边形"的直接读数。

## 需要与远端确认的取舍

- $q$（等边度）与 QEM 冗余度都可能被均匀重网格推高，而均匀重网格未必是 Artistic 目标，
  因此不能把单一指标当作标签；
- 方向类特征依赖模型朝向。若远端不做统一朝向规范化，这类特征只应在同一资产内部比较，
  不能跨资产直接比较。
