# Feature definitions

## Basic counts

- `vertex_count`：顶点数量；
- `face_count`：三角面数量；
- `edge_count`：无向唯一边数量；
- `component_count`：至少被一个面使用的顶点所形成的连通分量数量；
- `boundary_edge_count`：只被一个三角面使用的边数量；
- `nonmanifold_edge_count`：被三个或更多三角面使用的边数量。

## Face validity

- `zero_area_face_count`：面积小于等于 `zero_area_epsilon_ratio` 乘该网格中位面面积的面数
  （默认为中位面面积的 $10^{-6}$）。阈值取相对值而非绝对值，因为两个来源的尺度相差四个
  数量级（0.7 到 12160），一个固定的绝对 epsilon 在不同尺度上含义完全不同；
- `duplicate_face_count`：忽略顶点顺序后重复的额外三角面数量。

这些指标描述几何可用性，不直接定义 Artistic 标签。

## Triangle equilateral score

对边长为 $l_1,l_2,l_3$、面积为 $A$ 的三角形：

$$
q = \frac{4\sqrt{3}A}{l_1^2+l_2^2+l_3^2}
$$

- `equilateral_ratio`：$q>0.9$ 的面比例；
- `sliver_ratio`：$q<0.05$ 的面比例；
- `small_angle_ratio`：最小内角小于 $5^\circ$ 的面比例。

判读方向（2026-10-16 按学长原意更正）：**等边本身不是坏信号**。第二条判据的原话意思是
"不能为了满足形状规则而增加太多冗余的面"——要区分的是"为了形状规则而均匀铺满"（自动
重网格与扫描重建追求均匀采样，产出接近等边的三角形，且为此在平坦处也铺面）与"把面花在
需要的地方"。所以等边度只作**冗余面的伴随信号**：单独的高等边度不构成理由，`screening`
里没有任何规则以它单独判负，只有"等边 + 顶点冗余"的组合签名才报警
（`configs/screening/artistic_v1.yaml`）。

`sliver_ratio`（细长面比例）在这份数据上反而是能逐对分开两个来源的面形状量（Objaverse
更多细长面，p=0.003，见 `docs/OPEN_QUESTIONS.md`），与课题组论文 MeshRipple 的规则同向
（最小内角 <5° 的面占比 >20% 即丢弃）。本项目早期文档先把它写成"越接近 1 越好"，纠偏时
又写成"等边度高是坏的信号"，两次都过头；正确的位置在中间。

## Area distribution

`area_coefficient_of_variation` 是非零面积三角面的总体标准差除以均值。它仅描述面积差异，必须结合结构和局部位置解释。

## Artistic features（已实现）

判据见 `docs/LABELING_GUIDE.md`，实现见 `src/mesh_filter/features/artistic.py`。
`configs/features/artistic_v1.yaml` 里的开关名就是它写进特征表的列名。

| 列 | 定义 | 期望方向 |
| --- | --- | --- |
| `vertex_degree_mode_share` | 顶点度数分布的众数占比（度 1–12 分箱） | 高 = 好（度数集中） |
| `vertex_degree_entropy` | 同一分布的归一化香农熵（除以 $\log 12$） | 低 = 好 |
| `one_ring_edge_length_cv_median` | 每个顶点一环边长变异系数的中位数 | 待实测 |
| `local_edge_direction_anisotropy_mean` | 每个顶点入射边方向张量 $\sum d_i d_i^{\top}$ 的 $(\lambda_3-\lambda_2)/\lambda_3$ 之均值 | 待实测 |
| `neighboring_direction_consistency_mean` | 同一顶点入射边两两 $|\cos|$ 的均值，再对所有顶点取均值 | 待实测 |
| `curvature_density_correlation` | 顶点离散曲率与局部面密度的 Spearman 相关 | 正 = 好 |
| `qem_redundancy_median` | 顶点塌缩到一环邻居质心时的二次误差中位数，除以该顶点一环平均边长平方 | 高 = 好 |
| `redundant_face_share` | 不用改变形状就能删掉的面占比（平面 patch 内多铺的三角形），口径按 CGAL `remesh_planar_patches` | 低 = 好（判据二的核心度量） |

标"待实测"的三列是按判据推出来的猜测。合成对照集（见下节）已经验证了它们各自响应什么，但
"响应"不等于"能区分手工与扫描"——真实数据上的方向仍要与人工标注对一遍才能定下来。已经被
否掉过的例子：`local_edge_direction_anisotropy_mean` 曾被设想为"局部有主导方向 = 好"，但
八面体顶点（方向成对对称）与平面网格分别给出 0.50 和 0.49——任何入射方向成对对称的顶点
都会把这个量推向 0，与网格是怎么做出来的无关。

## 冗余的面（`redundant_face_share`）

判据二的核心度量：**不用改变形状就能删掉的面占比**。口径照 CGAL 的
`remesh_planar_patches`（见 `docs/RELATED_WORK.md`）：**先把坐标重合的顶点焊接**，再把
相邻面按法向夹角 ≤3° 聚成平面 patch，把 patch 边界上共线的边串成线段，只有线段端点与
多面交汇点需要顶点（corners）；一个 patch 无论内部铺得多密，都只需要 corners − 2 个
三角形。超出部分就是冗余——一个矩形需要 2 个三角形，铺成 8 个就浪费 6 个。

**焊接是关键的一步，不是清洁工作。** 语料里顶点分裂极其普遍：138 个校准样本中约九成
存在重合副本（最极端的 A0029 顶点数 17808、唯一位置仅 1460）。人看模型时重合副本就是
一个点，而按索引走邻接的 patch 算法看到的是孤岛，什么也聚不起来——第一轮的"结构型规则
化"漏网因此在 3° 下读出 0.000；焊接后同一模型读 0.49。坐标尺度相差三个数量级，焊接
容差取包围盒对角线的 $10^{-6}$。

弯曲的密集表面在这一列上仍然接近 0：球体的面在 3° 内两两不共面。这正是这一列与计数类
度量的分工——它区分"面花在形状需要的地方"与"面花在平地上"。

校准（三轮共 138 个人工标签，详见 `docs/OPEN_QUESTIONS.md`）：焊接后这一列在"人判
reject vs accept"上的 AUC 为 0.914（焊接前 0.815）；门槛维持 0.15 时保住全部历史认可
样本、新抓住 7 个漏放，代价是 1 个新增 accept 误报（r1 A0041，0.167）与 4 个
0.15–0.23 的 flag 样本被过判。**多容差被实测否掉**：把容差放宽到 10°/15°/20° 后 AUC
单调下降（20° 时掉到 0.50）——接受侧的光滑模型与浪费模型在宽容差下混成一团，这条路线
不再继续。仍待解决的是"大模型里的一小块平板"（局部窗口版本被接受样本的高值淹没，
暂无净收益）。

## 合成对照集（实测）

`src/mesh_filter/contrast.py` 生成构造已知的网格——均匀细分的球与环面、折线屋面、带凸包的
圆盘、盒子、棱柱——`tests/test_feature_contrast.py` 把"某个量是否响应它名字声称的性质"写成
断言。它能证明的只是这个量确实在量它声称的东西，**不能**替代盲审：这个性质能不能区分真实的
手工与扫描资产是另一个问题。实测结论（数字都来自那些断言）：

| 列 | 结论 |
| --- | --- |
| `equilateral_median` | 干净。同一格架、同轮廓下，等边格架给 1.000，压成细长条给 0.046（`sliver_ratio` 同步 0 → 1） |
| `equilateral_ratio` | 阈值化后动态范围本就很小；而且四边形网格的三角形只有 $q=\sqrt3/2\approx0.87$，够不着 0.9 的阈值——**四边形重网格的资产在这一列上是隐形的** |
| `qem_redundancy_median` | 完全按设计。细分层级 0→3 单调下降 0.873 → 0.471 → 0.132 → 0.033；粗而有折痕的盒子与棱柱在 0.6–1.2；平面网格为 0 |
| `curvature_density_correlation` | 有两个必须知道的边界，见下 |
| `vertex_degree_mode_share` / `entropy` | **方向与"手工"假设相反**：最集中的是均匀细分球（0.98）与环面（熵为 0），盒子只有 0.50。它量的是规则程度，而两个极端都可以很规则 |
| `one_ring_edge_length_cv_median` | 响应局部间距不均：同一拓扑的网格，均匀行距 0.17、疏密相间 0.37 |
| `local_edge_direction_anisotropy_mean` | 响应"细长 + 取向"：细长格架 1.00、等边格架 0.10；但跨原型家族不排序（平网格 0.50 > 棱柱 0.14） |
| `neighboring_direction_consistency_mean` | 同上：细长格架 1.00；手工端原型反而低（盒子 0.28、棱柱 0.30），家族间不排序 |

曲率-密度相关的两条边界：

**折痕看不见。** 折痕是外赋弯曲，内蕴角缺陷恒为零。把折线屋面交给这一列——无论是否把网格
加密到折痕上——答案都是空值"测不出来"，因为曲率项本来就是零。真实手工网格的"转折处"大多是
折痕，所以这一列能捕捉的不是折痕本身，而是真正带内蕴曲率的部位。

**均匀参数化有系统性负偏。** 角缺陷在顶点上的值约等于高斯曲率乘该顶点的面积（Gauss–Bonnet），
而局部密度是面积的倒数，所以即便表面上什么都没有，角缺陷也会与密度反相关：均匀环面给出
−0.98。把环圈朝外侧（曲率为正）挤过去才翻到 +0.43；凸包圆盘上顺曲率加密给 +0.96、逆着给
−0.68。

含义：这一列在 200 个人工标签上拿到 AUC 0.635 是事实，但它不是"密度跟着曲率走"的干净探测器，
筛查脚本不能只靠它。

## 共同约定

- 只在"在用顶点"上定义：在用顶点指至少属于一个三角面的顶点，孤立顶点不计入任何统计；
- 所有量对平移、旋转、统一缩放都不变。这条是硬要求：两个来源的尺度差四个数量级
  （Toys4K 最长边恒为 2.0，Objaverse 0.7–12160），任何带尺度的量都会被直接学成判别器；
- **测不出来时写空，不写 0**。`curvature_density_correlation` 在曲率或密度只有一个取值
  （平面、球面、规则网格）时无定义——那里的排名由浮点噪声决定，换个旋转就换个答案，
  留空表示"测不出来"，而不是"相关为零"；
- 网格过小或退化导致艺术特征算不出来时，`artistic_status` 记 `failed:<异常名>`、该行
  艺术特征列留空，但 `parse_status` 仍是 `parsed`：一个能解析的网格不该因为附加特征算
  不了就变成解析失败。

## QEM 的一处纠正

标准 QEM 误差在顶点自身求值恒等于零——顶点本来就在它所有邻接平面上。第一版实现就是这么
写的，实测对每种网格都返回 0，等于白算。现在求值点是**该顶点收缩到一环邻居质心后的位置**，
含义才真正是"删掉这个顶点会丢多少形状"。平面网格的邻居质心仍共面，读数接近 0（顶点冗余）；
闭合曲面的邻居质心偏离切平面，读数显著大于 0（顶点承担形状）。

归一化也纠正过一次。第一版除以包围盒对角线平方，全量 4567 个网格上这一列的中位数与 p75
全是 0.000、最大 0.036——细网格的每顶点误差在物体尺度下趋近于零，整列没有动态范围。现在
除以该顶点一环平均边长平方，含义变成"这个顶点相对于它的疏密程度承担了多少形状"，即判据的
"两个面够用的地方用了四个面"，最大值升到 0.315。合成对照集上细分层级 0→3 的单调下降
（0.873 → 0.033）就是新归一化带来的。

## 与远端确认过的取舍

- $q$（等边度）在自动重网格与扫描重建上都很高，而这两类都不符合目标；它与 QEM 冗余度
  都不能单独当标签用，必须组合；
- 方向类特征依赖模型朝向。若远端不做统一朝向规范化，这类特征只应在同一资产内部比较，
  不能跨资产直接比较。
